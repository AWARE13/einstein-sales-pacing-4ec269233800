Moving Company's Roundtable leadership. It's `noindex`'d and not linked from
anywhere public, but the URL itself is **not access-restricted** — anyone with
the link can view it. Please don't share the link outside Roundtable leadership.

through August; this moves to a full Aug–Oct quarterly view once Sept and Oct
goals are entered.

Source of truth / version history lives in the private `cos-amanda` repo at
