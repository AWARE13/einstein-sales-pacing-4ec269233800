How the color is decided — changed for the final day — bar length is each rep's % of August goal booked, same as always. Color is now a standing, not a projection: Super Green hit goal, Green finished at 90–99%, Yellow at 50–89%, Red under 50%.

Why it changed: for the first 30 days, color compared each rep's weekly pace against EMMA's Weekly Run Rate — the $/week still needed to close the gap. On the last day of the window EMMA stops publishing that column entirely (it returns a dash for every rep), because there is no remaining period to spread a run rate across. There is no pace left to project from, and no substitute figure has been invented here. Reading the month by % of goal achieved is the only honest option left. The "Gap to goal" column is now simply booked minus goal, display-only — and for reps still short it doubles as exactly what they need to close today.
